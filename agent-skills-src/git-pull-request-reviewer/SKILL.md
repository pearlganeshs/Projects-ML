# Pull Request Review Workflow
1. Check git diff or staged files for logic errors, edge cases, and unhandled exceptions.
2. Flag any hardcoded secrets, missing input validation, or performance bottlenecks.
3. Group feedback into **Must Fix**, **Suggestions**, and **Nitpicks**.
