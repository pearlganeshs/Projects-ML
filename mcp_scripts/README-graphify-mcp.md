# Graphify MCP Server

**MCP server name:** `graphify_kg_mcp`  
**Transport:** stdio  
**Script:** `mcp_scripts/mcp_graphify_server.py`

## Overview

The **Graphify MCP Server** exposes a local [Graphify](https://github.com/Graphify-Labs/graphify) knowledge graph (`graphify-out/graph.json` and `graphify-out/GRAPH_REPORT.md`) to AI coding assistants and agents over `stdio`. Instead of forcing an LLM to grep and read dozens of raw files, the server lets the agent query extracted entities, inspect module dependencies, trace shortest paths between components, and review architectural summaries with high token efficiency.

To verify the complete MCP `stdio` handshake and local graph read access, configure `GRAPHIFY_PROJECT_ROOT` and run `python mcp_scripts/test_graphify_mcp.py`.

### Built-In Guardrails & Capabilities
- **Read-Only Graph Inspection:** Provides `get_graph_stats`, `read_graph_report`, `search_nodes`, `get_node_neighbors`, and `find_shortest_path` without modifying source code or graph artifacts.
- **Path-Traversal Protection:** Restricts graph lookups strictly inside `GRAPHIFY_PROJECT_ROOT` (preventing `../` or symlink escapes).
- **Context-Window Protection:** Caps node search results (max `100`), neighbor hops (max `2`), and report reads (`max_chars` up to `100,000`) so large repositories do not overflow the AI context window.
- **Native Graphify CLI Support:** Works seamlessly alongside graphs generated by `graphifyy` (`graphify .` or `graphify ./raw`).

## Install and Run

### 1. Create Virtual Environment & Install Packages

**On macOS / Linux (Terminal):**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r mcp_scripts/requirements-graphify-mcp.txt
```

**On Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r mcp_scripts\requirements-graphify-mcp.txt
```

### 2. Build the Local Knowledge Graph

Navigate to your target project folder and run Graphify to generate `graphify-out/graph.json` and `graphify-out/GRAPH_REPORT.md`:

```bash
cd /path/to/your/project
graphify .
```

### 3. Configure Environment Variables

| Variable | Default | Purpose |
| :--- | :--- | :--- |
| `GRAPHIFY_PROJECT_ROOT` | Parent of `mcp_scripts` | Absolute path to the repository containing `graphify-out/`. |
| `GRAPHIFY_OUT_DIR` | `graphify-out` | Relative subdirectory inside `GRAPHIFY_PROJECT_ROOT` holding `graph.json` and `GRAPH_REPORT.md`. |

**On macOS / Linux:**
```bash
export GRAPHIFY_PROJECT_ROOT="/path/to/your/project"
python mcp_scripts/mcp_graphify_server.py
```

**On Windows (PowerShell):**
```powershell
$env:GRAPHIFY_PROJECT_ROOT="C:\path\to\your\project"
python mcp_scripts\mcp_graphify_server.py
```

### 4. Run the Smoke Test

Verify the MCP `stdio` handshake and graph query tools:

```bash
python mcp_scripts/test_graphify_mcp.py
```

## Register in Your MCP Host JSON Configuration

Add `graphify` to your MCP client configuration (use `.venv/bin/python` on macOS/Linux or `.venv\Scripts\python.exe` on Windows):

```json
{
  "mcpServers": {
    "graphify": {
      "command": "/path/to/.venv/bin/python",
      "args": ["-u", "/path/to/mcp_scripts/mcp_graphify_server.py"],
      "env": {
        "GRAPHIFY_PROJECT_ROOT": "/path/to/your/project",
        "GRAPHIFY_OUT_DIR": "graphify-out"
      }
    }
  }
}
```

*(Note: Graphify also ships an embedded MCP command via `uv tool install "graphifyy[mcp]"` and `graphify ./raw --mcp`, while `mcp_graphify_server.py` gives you a lightweight, auditable `FastMCP` wrapper matching your local MCP suite.)*

## Tool Usage Examples (JSON Payloads)

1. **Inspect graph metadata and node/edge counts** — call `get_graph_stats`:
```json
{}
```

2. **Read the generated architectural summary** — call `read_graph_report`:
```json
{"max_chars": 20000}
```

3. **Search entities (functions, classes, files, concepts)** — call `search_nodes`:
```json
{"query": "oracle", "node_type": "function", "limit": 20}
```

4. **Inspect incoming/outgoing relationships for a node** — call `get_node_neighbors`:
```json
{"node_id": "mcp_oracle_server.py::query_table", "direction": "both", "max_edges": 30}
```

5. **Trace dependency path between two nodes** — call `find_shortest_path`:
```json
{"source_id": "main.py::run", "target_id": "db.py::connect"}
```
